# Core

The core module has essential helper functions often used in other modules, but may be helpful on their own.

## Member Variables

| Variable | Description | Type
|---|---|---|
| [`places`](#Places) | A table of keyed items, where the key is the place and the value specifies a snap point, a container, or a zone. | table
| [`boards`](#Places) | A table of base objects for places, mostly boards or mats with snap points. Those may have multiple states. | table
